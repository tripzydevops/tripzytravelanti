## 1. Executive Summary & Core Platform Thesis

### Pillar 1: Direct Deal & Booking Transaction Commissions (8% – 15%)
* **Mechanism:** When users discover and redeem hotel stays, restaurant dining vouchers, beach club passes, or yacht charters on Tripzy, Tripzy retains an **8% to 15% marketplace commission** on gross booking volume (GMV).
* **Payment Flow:** Seamlessly processed via Turkish payment gateways (Iyzico / PayTR) with automated split payouts to merchants.

### Pillar 2: The Viral Flash Lottery & "Consolation Voucher" Engine
* **The Traditional Giveaway Flaw:** In typical lotteries, 99.9% of entrants lose, receive nothing, and churn.
* **The Tripzy Conversion Funnel:** 
  1. 10,000 users share the lottery to Instagram Stories to win 1 free night at a boutique hotel.
  2. The cryptographic draw selects 1 verified winner via SHA-256.
  3. **The 9,999 non-winners automatically receive a 48-Hour Consolation VIP Voucher** (e.g., *“You didn't win the free stay, but here is an exclusive 25% discount valid for 48 hours”*).
  4. At a conservative **3% conversion rate**, that single free lottery generates **300 immediate paid bookings**, delivering **₺150,000+ in merchant revenue** and **₺22,500 in net commission to Tripzy**.

```
  10,000 Entrants ──► 1 Grand Prize Winner
         │
         └──► 9,999 Non-Winners ──► Consolation Voucher (25% off / 48h)
                                         │ (3% Conversion Rate)
                                         ▼
                               300 Immediate Paid Bookings
                               (₺22,500 Net Commission to Tripzy)
```

### Pillar 3: Google AdMob & Rewarded Video Ads Engine (Ödüllü Video Reklamlar)
* **The Model:** Users choose to watch a 15–30 second sponsor video to earn **+1 Instant Flash Lottery Ticket** or **unlock a secret 5% extra discount voucher**.
* **Why Google Rewarded Ads Excel:**
  * **100% Policy Compliant:** Google explicitly supports opt-in rewarded video formats for digital tokens/tickets.
  * **Daily Cap (3 videos/day):** Protects user experience and maintains peak advertiser eCPMs.
  * **VIP Member Exemption:** Tripzy VIP subscribers get all bonus tickets automatically **without ads**, heavily boosting VIP subscription conversions.
* **The Math & eCPM Breakdown:**
  * **Turkish Rewarded Video eCPM:** **$2.50 – $6.00** per 1,000 views.
  * **Foreign Tourist / Expat eCPM in Turkey:** **$15.00 – $35.00** per 1,000 views.
  * **Projected Revenue:** 20,000 daily ad impressions @ $4.50 blended eCPM = **$2,700/mo (~₺92,000/mo)**. At 100k MAU, this scales to **$13,500/mo (~₺460,000/mo)** in pure passive profit.

### Pillar 4: Tripzy VIP / Plus Recurring Subscriptions (MRR)
* **Pricing:** **₺99 / month** or **₺799 / year** (~$3 – $25/yr).
* **VIP Member Privileges:**
  * **$3\times$ to $5\times$ Lottery Ticket Odds Multiplier** on all active flash draws.
  * **Automatic Lottery Entry:** Entered into every weekly drop without manual re-sharing.
  * **100% Ad-Free Experience:** Bonus tickets and secret perks unlock without watching video ads.
  * **Zero Platform Booking Fees & Secret 70%+ Off Flash Deals.**
  * **Priority Concierge AI & Geofenced VIP Perks.**
* **Financial Projection:** At 50,000 active users, a 4% VIP conversion (2,000 subscribers) yields **₺198,000 / month in pure recurring MRR**.

## 4. Flash Lottery & Instagram Share Verification Engine

### 4.1 3-Tier Verification Pathways
Due to Meta API privacy constraints on consumer Instagram accounts, verification uses a 3-tier hybrid mechanism:

```
                  ┌────────────────────────────────────────────────────────┐
                  │          USER TAPS "SHARE TO INSTAGRAM TO WIN"         │
                  └───────────────────────────┬────────────────────────────┘
                                              │
         ┌────────────────────────────────────┼────────────────────────────────────┐
         │                                    │                                    │
         ▼                                    ▼                                    ▼
┌──────────────────┐               ┌──────────────────┐               ┌──────────────────┐
│ METHOD 1: TAG    │               │ METHOD 2: REFER  │               │ METHOD 3: AI OCR │
│ @tripzydeal      │               │ Unique QR / Link │               │ Upload Screenshot│
│ Webhook Event    │               │ Friends Click    │               │ Vision OCR Check │
└────────┬─────────┘               └────────┬─────────┘               └────────┬─────────┘
         │                                    │                                    │
         └────────────────────────────────────┼────────────────────────────────────┘
                                              │
                                              ▼
                              ┌───────────────────────────────┐
                              │  MINT LOTTERY TICKET IN DB    │
                              │  (#TRPZ-LOT-89210)            │
                              └───────────────────────────────┘
```

1. **Method 1 - Story Canvas & Deep Link Tracking (`story_canvas` / `referral_click`):**
   - Generates a branded 9:16 Instagram Story Canvas with deal banner, `@tripzydeal` tag sticker, and the user's referral QR code (`#TRPZ-XXXXXX`).
   - Emits Web Share API intent and automatically mints an active lottery ticket (`TRPZ-LOT-XXXXX`).
2. **Method 2 - AI Vision OCR Screenshot Verification (`ocr_screenshot`):**
   - Users upload a quick screenshot of their posted Instagram Story.
   - The OCR service analyzes the image for `@tripzydeal` tag presence, partner handle, and deal badge, awarding a verified ticket in $<2$ seconds.
3. **Method 3 - Points Exchange (`points_exchange`):**
   - Allows users to convert 50 Tripzy loyalty points into +1 additional lottery ticket.

### 4.2 Provably Fair Cryptographic Winner Selection
All lottery draws utilize cryptographic hashing to guarantee transparency and prevent manipulation:

$$\text{Draw Seed} = \text{SHA256}(\text{CampaignID} + \text{Timestamp} + \text{Salt})$$

$$\text{Ticket Hash} = \text{SHA256}(\text{TicketNumber} + \text{Draw Seed})$$

- Tickets are sorted deterministically based on their individual hash values against the cryptographic seed.
- Winners receive an instant 100% FREE digital voucher stub inside `WalletPage.tsx`.

### 4.3 API Endpoints Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/lottery/campaigns` | Lists all active and upcoming flash lottery campaigns. |
| `POST` | `/api/v1/lottery/campaigns` | Creates a new flash lottery campaign (Merchant / Admin). |
| `POST` | `/api/v1/lottery/claim-ticket` | Mints a verified ticket via share or points exchange. |

## 6. Supabase Database Schemas & Migrations

```sql
-- 1. Flash Lottery Campaigns Table
CREATE TABLE IF NOT EXISTS public.lottery_campaigns (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    deal_id UUID REFERENCES public.deals(id) ON DELETE CASCADE,
    merchant_id UUID REFERENCES public.profiles(id),
    title VARCHAR(255) NOT NULL,
    title_tr VARCHAR(255),
    description TEXT,
    description_tr TEXT,
    prize_description TEXT NOT NULL,
    total_winners INT DEFAULT 1,
    starts_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    ends_at TIMESTAMPTZ NOT NULL,
    status VARCHAR(50) DEFAULT 'active', -- 'active', 'drawn', 'cancelled'
    winning_ticket_ids UUID[],
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Minted Lottery Tickets Table
CREATE TABLE IF NOT EXISTS public.lottery_tickets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    campaign_id UUID REFERENCES public.lottery_campaigns(id) ON DELETE CASCADE,
    user_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE,
    ticket_number VARCHAR(50) NOT NULL UNIQUE, -- e.g. TRPZ-LOT-89210
    verification_method VARCHAR(50) NOT NULL,  -- 'story_canvas', 'ocr_screenshot', 'points_exchange'
    verified_at TIMESTAMPTZ DEFAULT NOW(),
    is_winner BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Cryptographic Draw Audit Table
CREATE TABLE IF NOT EXISTS public.lottery_draws (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    campaign_id UUID REFERENCES public.lottery_campaigns(id),
    winning_ticket_id UUID REFERENCES public.lottery_tickets(id),
    winning_user_id UUID REFERENCES public.profiles(id),
    draw_seed VARCHAR(255) NOT NULL, -- Cryptographic seed for fair winner selection
    drawn_at TIMESTAMPTZ DEFAULT NOW()
);
```
